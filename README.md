# Prompt Library

Zusammenhanglose Sammlung von Prompts für LLMs und Rules für opencode.

## opencode-Rules

Die Dateien aus `rules/` nach `~/.config/opencode/instructions/` kopieren. Sie werden dort global geladen.

Für ein einzelnes Projekt die Dateien stattdessen nach `.opencode/instructions/` im Projektverzeichnis legen.
